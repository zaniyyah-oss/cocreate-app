# CoCreate

Set up the visual foundation for a web app called CoCreate — a conversation and

publishing brand where believers engage with essays, teachings, podcasts, and

devotionals. The feel should be bright, warm, and inviting — easy to consume,

not heavy or corporate.

Typography: Poppins only, weights 400–900. Never use a cursive or script

typeface anywhere, including for the wordmark — the wordmark "CoCreate" is

always set in Poppins 900, both C's capitalized, no period.

Color system (use as CSS variables):

--navy: #181A4D

--fire: #FF340C

--periwinkle: #8A96E0

--lime: #CAC307

--light-green: #DCE07A

--amber: #FFAE00

--teal: #0F4A42

--burgundy: #441B07

--blush: #E990A2

--cream: #FBF8ED

--ink: #20201C

--muted: #8A8678

Design rule that matters more than the palette itself: the base surface is

cream/white. Color shows up as small, deliberate pops — a tag, an icon

background, a left border accent, a tinted photo overlay — never as a large

solid-color panel or block. Do not build a dark navy sidebar or a solid

colored hero section. Do not use a yellow/orange checkerboard pattern

anywhere — it reads as visually overwhelming.

Build a simple style guide page showing: the color swatches, type scale,

button states, a content-type tag component (four variants: Teaching/amber,

Essay/light-green, Podcast/teal, Devotional/lime), and one example photo

card with a tinted color overlay. Nothing else yet.

Also see the attached HMTL file for the desktop and mobile views of the platform
